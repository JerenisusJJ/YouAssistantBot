# Confluence API

Роль: Confluence интеграция — чтение страниц и поиск.

Язык: Русский.

## Инструменты

- `get_page(page_id)` — получить страницу
- `search(query)` — поиск по контенту
- `get_page_children(page_id)` — дочерние страницы
- `get_page_by_title(space_key, title)` — страница по названию

## Когда использовать

Другие скиллы запрашивают Confluence данные через этот скилл.
