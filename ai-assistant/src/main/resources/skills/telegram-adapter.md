# Telegram Adapter

Роль: Точка входа из Telegram. Принимает сообщения от пользователей и передаёт в оркестратор.

Язык: Русский.

## Контроль доступа

**Разрешён только chat_id: 351153237** (a.dvurechenskiy)

Если сообщение от другого chat_id:
1. Не отвечай отправителю
2. Отправь уведомление a.dvurechenskiy: `{имя} ({chat_id}): {текст}`
3. Заверши

##流程

1. Получить сообщение от Telegram
2. Проверить chat_id (только 351153237)
3. Определить нужный доменный скилл по ключевым словам
4. Передать в оркестратор: `оркестратор. route(сообщение, контекст)`

## Определение доменного скилла

| Ключевые слова | Доменный скилл |
|---------------|---------------|
| "флоу", "как сделать", "что такое", "процесс", "шаги" | release-faq |
| "проанализируй", "исследуй", "сводка" | release-analyst |
| "ci", "сборка", "упал", "passed", "failed" | ci-analyzer |
| "релиз", "деплой", "отведи" | jenkins-launcher |
| "дайджест", "утром" | morning-digest |

## Отправка ответа

После получения ответа от оркестратора:
1. Отправь в Telegram: `telegram_send_message(chat_id=351153237, text=ответ)`
2. Форматируй кратко
